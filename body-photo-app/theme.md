# PHYSIQUE — デザイン仕様

## テーマ概要

白ベース + 落ち着いたピンク（Blush）をアクセントとした配色。
優しく・女性的で、毎日使っても疲れないトーンを目指す。

---

## カラー

### CSS Variables

```css
:root {
  /* ── Backgrounds ── */
  --bg:          #FFFFFF;        /* メイン背景（純白） */
  --surf-1:      #F5F5F5;        /* カード・カレンダーセル */
  --surf-2:      #EBEBEB;        /* 入力欄・ボタン背景 */
  --surf-3:      #E0E0E0;        /* アイコン背景・深いサーフェス */

  /* ── Borders ── */
  --border:      rgba(0,0,0,0.08);
  --border-hi:   rgba(0,0,0,0.16);

  /* ── Accent: Blush Pink ── */
  --accent:      #C89898;
  --accent-dim:  rgba(200,152,152,0.12);  /* 選択セル背景 */
  --accent-dim2: rgba(200,152,152,0.06);  /* ホバー背景 */

  /* ── Text ── */
  --t1: #111111;   /* 見出し・本文 */
  --t2: #666672;   /* サブテキスト */
  --t3: #AAAAAB;   /* ラベル・プレースホルダー */

  /* ── Semantic ── */
  --green: #16A34A;   /* 体重減少・ポジティブ */
  --red:   #E53935;   /* 削除・警告・今日マーカー */

  --red-dim:  rgba(229,57,53,0.10);
  --blue-dim: rgba(25,118,210,0.10);
}
```

## コンポーネント

### カレンダー（ホーム）

- グリッド: 7列 × `grid-auto-rows: 44px`
- セル: 右・下ボーダーでグリッド線を表現
- 今日: 赤サークル（`var(--red)`）
- 選択日: Blushサークル（`var(--accent)`）
- 記録あり: 体重 + 日付を表示、クリック可

### デイパネル（ホーム下部）

- 日付クリックで展開
- 体重（大）+ 写真プレビュー
- 写真なし時: ダッシュ枠 + 「写真なし」

### 記録追加フォーム

- 日付: 左右ナビ＋ピル型日付表示
- 体重: Barlow Condensed 34px 入力 + ±0.1/±0.5 調整ボタン
- 写真: コンパクトボタン（1行）
- 保存: 全幅 pill ボタン（`var(--accent)`）

### 比較モーダル

- ボトムシートスタイル（translateY アニメーション）
- オーバーレイ: rgba(0,0,0,0.38) + blur(3px)
- 写真ありセルのみ選択可能
- 選択済み: Blushサークル + 体重テキストがアクセント色
- カメラドット: accent 色の 5px 丸（opacity 0.35）

### セッティングリスト

- `set-ico` アイコン枠 36×36px
  - 緑系: `rgba(200,255,51,0.13)`
  - 青系: `rgba(68,153,255,0.13)`
  - 赤系: `rgba(255,68,68,0.13)`
  - ニュートラル: `rgba(255,255,255,0.06)`
- Danger行: `var(--red)` テキスト
