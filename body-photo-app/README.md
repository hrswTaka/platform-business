# PHYSIQUE

Body photo and weight tracking app prototype built with Expo and React Native.

## Development

```bash
npm install
npm run web
```

Useful scripts:

- `npm start` - start Expo
- `npm run ios` - start on iOS simulator
- `npm run android` - start on Android
- `npm run web` - start the web preview

## Design Notes

The app uses a white base with a blush accent (`#C89898`). See `theme.md` for the detailed visual specification.
