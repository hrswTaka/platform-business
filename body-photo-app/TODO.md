# 体重×写真記録アプリ TODO計画

## Context

筋トレ・ダイエットを継続している人が「体重」と「写真」を別々に管理している問題を解決する。
数字の停滞期でも見た目の変化を確認できることで継続モチベを維持できる。

**方針:**
- **プラットフォーム: Next.js PWA** → PC Webブラウザ + スマホホーム画面追加を1コードでカバー
- **ストレージ: 端末ローカルのみ（IndexedDB）** → 写真はサーバーに一切送らない。裸写真の漏洩リスクゼロ
- **将来: Expoアプリ化** → ユーザーが増えてストレージ・カメラ体験の限界が出てから検討

---

## 技術スタック

| 要素 | 採用 | 理由 |
|---|---|---|
| フレームワーク | Next.js 14 + TypeScript | PWA化しやすい、Vercelデプロイ簡単 |
| スタイル | Tailwind CSS | 高速開発 |
| DB | Dexie.js（IndexedDB wrapper） | 写真をブラウザ内に保存 |
| PWA | next-pwa | オフライン対応、ホーム画面追加 |
| CSV | Papa Parse | CSVインポート/エクスポート |
| 写真アップロード | react-dropzone | ドラッグ&ドロップ + ファイル選択 |
| 画像合成 | html2canvas | Instagram出力用（クライアント側レンダリング） |

---

## データモデル

```ts
// 1レコード = 1日の記録
Record {
  id: string          // UUID
  date: string        // "2026-05-23"
  weight: number      // 体重 (kg)
  waist?: number      // ウエスト (cm) - want
  photoBlob?: Blob    // 写真（端末内にのみ保存）
  note?: string       // メモ
  createdAt: number   // timestamp
}
```

## 画面構成

```
/ (ホーム/記録一覧)
  └── 時系列で記録カード表示

/record (新規記録)
  └── 日付 / 体重 / ウエスト / 写真アップロード or カメラ

/gallery (ギャラリー)
  └── 写真のみグリッド表示（時系列 or 体重順）

/compare (比較)
  └── 2枚を縦並び（上: Before / 下: After）← スマホ縦持ちフレンドリー
  └── 横並びに切り替えも可能（オプション）

/settings
  └── CSVエクスポート / CSVインポート / データ削除
```

## Instagram出力仕様

### レイアウトパターン（ユーザーが選択）

| パターン | 解像度 | 用途 |
|---|---|---|
| **縦2枚並び（4:5）** | 1080×1350px | Instagram投稿メイン ← 推奨デフォルト |
| 正方形2枚並び（1:1） | 1080×1080px | Instagram投稿（上下に2枚） |
| ストーリー縦（9:16） | 1080×1920px | Instagram Stories |

### 出力に含む要素
- 上段: Before写真（日付・体重テキストオーバーレイ）
- 下段: After写真（日付・体重テキストオーバーレイ）
- 差分ラベル: 「-△kg」「+△日」を中央に表示（オプション）
- ブランドロゴ/透かし（将来対応）

### 技術実装
- `html2canvas` または Canvas API でクライアント側レンダリング
- JPEG/PNG でダウンロード（サーバー不要）
- 写真は保存時に正方形クロップ（1:1）を基本とする

## プライバシー方針（重要）
- **写真はサーバーに一切送らない**（IndexedDB = 端末内のみ）
- プライバシーポリシーに「写真はお使いの端末内にのみ保存されます」と明記
- HTTPSのみで提供（PWA要件にも合致）
- 将来クラウド機能を追加する場合は、E2E暗号化を前提に設計
