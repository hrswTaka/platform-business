# アプリケーション アイデア集

## 1. 筋トレ実施管理アプリ

音声入力で筋トレ内容を入力すると、自動で実施内容を整理・記録してくれるアプリ。

## 2. 食材ベースのレシピ提案アプリ

- 家にある食材を入力
- カロリーや脂質などの栄養上限を設定
- 条件に合ったレシピを提案してくれる機能

## 3. 食材ベースのレシピサイト連携アプリ

- 家の食材を入力
- カロリーなどの栄養上限を入力
- 対象のレシピサイトに飛んで該当するレシピを見つけられる機能
- 2つ目とコンセプトが近いが、提案ではなく外部サイト連携型

## 4. メンズエステのアダルト記事売買サイト

ワクストのようなメンズエステに関するアダルト記事の売買プラットフォーム。

## 5. ファンサイトプラットフォーム

様々なジャンルのファン活動向けのコミュニティ・情報共有プラットフォーム。
- ボディービルダーのファンサイト
- 推し活コミュニティ
- YouTuberファンサイト
- その他、様々なジャンルに対応

## 6. 推し活アプリ

推し活の記録・管理・情報共有ができるアプリ。

## 7. 個人クリエイター×店舗マッチングサービス

個人で料理などの商品を製造できるが、店舗を持たない人と、空きスペースや販売チャネルを提供できる店舗をマッチングするサービス。
