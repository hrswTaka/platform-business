# プラットフォーム企画検討 (2026-05-07)

## 検討中の候補

### 1. アダルト販売プラットフォーム（WAKUST型）

**リファレンス**: https://wakust.com/

**ビジネスモデル案**
- トランザクション手数料（クリエイター売上の15〜30%）
- クリエイター向けプレミアム機能サブスク
- ファン向けプレミアム会員

**決済システム（重要な発見）**

WAKUSTが使用している決済方式:
- **ポイント中間層構造** - ユーザーがまずポイントを購入 → ポイントでコンテンツ購入
  - この構造によりStripe/PayPal等の規約問題を回避
- **実装PSP**:
  - BitCash（デジタル通貨。アダルト・ゲーム向けに最適化）
  - JCB（VISA/Mastercardより寛容）
  - マネックスコネクト（銀行振込代行）
  - ATON（コンビニ後払い）
  - Paidy（BNPL）
  - PAY AFTER（BNPL）

**結論**: 日本市場では決済問題はほぼ解決可能。決済は最大の障壁ではない。

**強み**
- ARPU（Average Revenue Per User）が高い
- ユーザーの離脱率が低い（クリエイターとの強い関係性）
- OnlyFans、Fanboxなど実証済みビジネスモデル

**課題**
- Google/Meta広告が使えない（SEO、SNS流入に依存）
- 強い既存プレイヤーが存在（FANZO等）
- **差別化軸が未定**

**差別化の候補軸**
1. ジャンル特化（同人、コスプレ、音声作品など）
2. クリエイター取分を上げる
3. SNS機能を強化（ファン⇔クリエイターの関係を深める）
4. 海外展開（英語圏向けに同じ仕組み）

**次のステップ**
- [ ] WAKUSTの詳細調査
  - どんなコンテンツが売られているか（動画？画像？テキスト？音声？）
  - クリエイターとファンの関係性（フォロー？DM？）
  - UX・機能面で「いいな」と思った部分
  - 「改善できそう」と感じた部分
- [ ] 差別化軸を1つ以上に絞る

### 2. 筋トレSNS（ジム×ワークアウトログ）

**コンセプト**
- ユーザーが「今どこのジムでどんな筋トレしたか」を投稿
- ジム検索、トレーニング記録、SNS機能を統合

**ビジネスモデル案**
- プレミアム会員（詳細分析、AIトレーニングプログラム推奨等）
- ジム・スタジオとのパートナーシップ（掲載料、集客フィー）
- プロテイン・トレーニング器具のアフィリエイト/EC
- パーソナルトレーナーのマッチング手数料

**強み**
- Meta/Google広告で集客可能
- App Store掲載OK
- インフルエンサーマーケティングとの相性が良い
- ジムが自然な集客チャネルになる

**課題**
- 競合が多い（Strava、Strong、Hevy等）
- マネタイズまでユーザー数が必要（成長に時間）
- 「どこで筋トレしたか」だけでは差別化が弱い

**必要な検討**
- SNS設計の工夫（拡散性をどう高めるか）
- ジムとのパートナーシップの実現可能性
