# デジタルコンテンツ成果物販売プラットフォーム企画

## コンセプト
「記事などを作ってその生地を販売するプラットフォーム」

デジタルコンテンツの完成品（記事、テンプレート、データセット等）をクリエイターが制作・販売できるCtoC マッチング型プラットフォーム。

## 基本方針
- **プラットフォームタイプ**：CtoC マッチング型
- **供給側**：コンテンツクリエイター
- **需要側**：企業、ブロガー、マーケター等（検討中）
- **キーポイント**：ストック型ビジネス（一度作ったら何度も売れる）

---

## 検討中のコンテンツ種類

### 1. SEO最適化済み記事
- ブログ、メディアサイト用にそのまま使える完成品
- 10,000字レベルのハイクオリティ記事
- キーワード、構成、ファクトチェック済み

### 2. 記事テンプレート・パッケージ
- 記事の構成テンプレート
- 執筆ガイドライン
- 見出し案、CTA案
- カスタマイズして使える素材

### 3. データセット・リサーチレポート
- 市場調査データ
- 業界分析レポート
- 統計情報

## 次のステップで詰めるべきポイント

### 1. 「生地」の具体的なタイプ
- **完全完成品重視**：そのまま使える記事
- **カスタマイズ重視**：テンプレート＆ガイド
- **情報資産重視**：データセット＆レポート
- → どれを軸にするか

### 2. 購入者ターゲットの定義
- **企業・メディア媒体**：大量コンテンツ購入、単価高
- **個人ブロガー**：少量購入、単価低、数が多い
- **マーケター・SEO業者**：業務用、継続購入
- → どのセグメントを優先するか

### 3. ビジネスモデル詳細
- **販売形式**：買い切り / サブスク / ライセンス（期間制限付き）
- **手数料率**：10-30%（競合調査必須）
- **独占販売**：クリエイターは1つのプラットフォームのみ
- **多重販売**：複数プラットフォームでの並行販売を許可
- **価格帯**：記事タイプ・質で分層

### 4. 既存サービスとの差別化
- **note**：個人のコンテンツ配信が主。プロフェッショナル向けではない
- **Gumroad**：多様なデジタルコンテンツだが、マーケットプレイス機能は弱い
- **Creative Market**：デザイン素材特化
- → 記事・コンテンツ専門性 or 高品質認定 or 業界特化など

### 5. 供給の確保方法
- **クリエイター確保**：既存ライター、フリーランスをどう集めるか
- **品質管理**：レビュー・承認プロセス
- **継続性**：単発売上 vs 継続的な供給を促す仕組み
- **インセンティブ**：ロイヤリティプログラム、ランキング、推奨枠など

### 6. ネットワーク効果の強さ
- 供給者増 → 買い手増 → 供給者がさらに増える、の好循環が作れるか
- 買い手がいないと供給者は来ない。鶏と卵問題をどう解くか
