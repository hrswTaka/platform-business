# 事業アイデア整理

軸：人の計測 × ビジネス
- あらゆる人が自分の可能性と向き合える社会の実現
- 人の能力のオープンソース化
- 曖昧なものを定量化して新たな価値・市場を生み出す

- どんなスポーツ・動作でも対応

**セルフポージングパーソナルトレーナー**

**姿勢評価アプリ**
- 定量評価 + MBTIライクなレポート販売ビジネス

**ボディビルポーズ評価**
- ポーズ＋表情を自動採点

- 横断的にジムへ登録できる仕組み
